Ein Protokoll, das prüft, was Ihre Agenten behaupten.

Agenten schreiben ihre Hypothesen, Läufe, Ergebnisse und Behauptungen in HypGraph. Es lehnt eine Zahl ab, die kein Ergebnis erklärt, „immer“ ohne die Zählungen und „ausgeschlossen“ ohne eine Suche mit ausreichender Teststärke, und leitet aus dem Protokoll bei jedem Lesen ab, was gezeigt ist und was gefährdet ist.

Was es ablehnt

Überbehauptungen kommen nicht ins Protokoll.

Sie wurden beim Erstellen dieser Seite in ein Testprotokoll geschrieben. Die Engine lehnte jede mit einem Code und dem ab, was zu korrigieren war; die Neufassung darunter, mit denselben Belegen, wurde angenommen.

Acht Regeln

Jede Regel ist ein Fehler, der tatsächlich gemacht wurde.

HypGraph entstand aus einem Team von KI-Agenten, das lange Untersuchungen durchführte, und aus den Fehlern, die sie trotz gegenteiliger Anweisungen machten. Jeder wurde zu einer Regel, die das Protokoll beim Schreiben der Arbeit durchsetzt — nicht zu einem Ratschlag, der hofft, befolgt zu werden.

Der Stand wird abgeleitet

Kein Feld sagt „bestätigt“. Prüfung, Risiko, Stützung und Belegstärke werden beim Lesen aus dem Protokoll berechnet.

Nur Anhängen

Verkettet mit SHA-256. Korrekturen sind neue Versionen; Rückzüge bleiben im Protokoll. verify() erkennt eine Änderung.

Prüfungen fixieren Versionen

Korrigieren Sie eine geprüfte Behauptung, wird ihre Prüfung veraltet. Eine Entscheidung, die auf der alten Version beruht, wird zur Überprüfung markiert.

Behauptungen tragen Zahlen

Die Zahlen einer Behauptung sind an Ergebnisfelder gebunden. Eine Zahl ohne Quelle wird abgelehnt — der häufigste Weg, auf dem Zusammenfassungen danebenliegen.

Unabhängigkeit wird gezählt

Drei Ergebnisse aus einem Lauf sind eine Beleglinie, nicht drei. Linien, die Daten oder eine Quelle teilen, verschmelzen.

Ausschlüsse brauchen Teststärke

„Schließt aus“ erst, nachdem gezeigt wurde, dass eine Suche eine eingepflanzte Antwort findet. Sonst ist das Ergebnis nicht schlüssig.

Autoren prüfen sich nicht selbst

Nur Urteile benannter Prüfer zählen, und nie über ihre eigene Arbeit. Die aller anderen werden als Kommentare aufbewahrt.

Instrumente sprechen für sich

Nur der Laborausführer zeichnet einen Laborlauf auf. Ein Lauf, den Sie beschreiben, wird als Ihr Bericht markiert.

Die Arithmetik von nie

Fehler in Tests lassen immer noch pro Million Nutzungen zu.

Ein Agent, der in seinen Tests keinen sieht, schreibt „das passiert nie“. Das Protokoll lehnt diesen Satz ab und verlangt die Zählungen, dann nennt es, was sie in dem Maßstab offenlassen, in dem Sie einsetzen.

Die Arithmetik, Schritt für Schritt

Fehler nicht ausgeschlossen bei Nutzungen, mit 95 % Konfidenz, aus in Tests.

Diese Seite hat ein Protokoll

Wir unterwerfen diese Seite den Regeln, die sie beschreibt.

Die Zahlen oben sind Behauptungen in einem HypGraph-Protokoll, das mit der Seite erstellt wird. Das Instrument des Builds misst sie, ein Prüfer misst jede auf anderem Weg erneut, und der Text der Seite wird mit hypgraph check gegen das Protokoll geprüft — eine Zahl, die das Protokoll nicht enthält, schafft es nicht auf die Seite. Öffnen Sie es in der App oben unter Das Protokoll dieser Seite, oder laden Sie das Bundle herunter und verifizieren Sie es selbst.

Vertrauen

Was das Protokoll zeigt und was es nicht behauptet.

✓ Es zeigt

  • dass kein Ereignis nach dem Schreiben geändert wurde: Jeder Schreibvorgang wird in eine Kette gehasht, die jeder erneut prüfen kann;
  • welche Zahlen einer Behauptung an welches Ergebnis gebunden sind und welcher Lauf es erzeugt hat;
  • wer was gegen welche Version geprüft hat und ob diese Version noch gilt;
  • was fällt, wenn eine Prämisse zurückgezogen wird.

— Es behauptet nicht

  • dass eine Behauptung wahr ist. Es prüft das Geschriebene gegen das Aufgezeichnete;
  • ein Modell besser denken zu lassen. Es hält die Überbehauptungen eines Modells aus dem Protokoll heraus;
  • irgendetwas über die Telemetrie, die in einem Bundle mitreist: Sie liegt außerhalb der Hash-Kette;
  • die Ereignisse zu prüfen, die ein Bundle mit Geltungsbereich verbirgt. Die Verifikation meldet, wenn ein Bundle einen Geltungsbereich hat.

Es läuft dort, wo Sie es ausführen: eine lokale Datei, kein Konto, keine eigenen Netzwerkaufrufe. Releases werden per Trusted Publishing aus GitHub Actions auf PyPI veröffentlicht.
