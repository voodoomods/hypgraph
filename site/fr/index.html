Un registre qui vérifie ce qu'affirment vos agents.

Les agents écrivent dans HypGraph leurs hypothèses, exécutions, résultats et affirmations. Il refuse un nombre qu'aucun résultat n'explique, « toujours » sans les décomptes et « exclu » sans une recherche suffisamment puissante, et déduit du registre, à chaque lecture, ce qui a été démontré et ce qui est menacé.

Ce qu'il refuse

Les surinterprétations n'entrent pas dans le registre.

Elles ont été écrites dans un registre de test lors de la construction de cette page. Le moteur a refusé chacune avec un code et ce qu'il fallait corriger ; la réécriture ci-dessous, avec la même évidence, a été acceptée.

Huit règles

Chaque règle est une erreur qui a réellement été commise.

HypGraph est né d'une équipe d'agents d'IA menant de longues recherches, et des erreurs qu'ils commettaient malgré les consignes. Chacune est devenue une règle que le registre applique au moment où le travail est écrit, et non un conseil qui espère être suivi.

Le statut est dérivé

Aucun champ ne dit « confirmé ». La relecture, le risque, le soutien et la force de l'évidence sont calculés à partir du registre au moment de la lecture.

Ajout seul

Chaîné avec SHA-256. Les corrections sont de nouvelles versions ; les retraits restent dans le registre. verify() détecte une modification.

Les relectures épinglent des versions

Si vous corrigez une affirmation vérifiée, sa vérification devient périmée. Une décision fondée sur l'ancienne version est signalée à revoir.

Les affirmations portent des nombres

Les nombres d'une affirmation sont liés à des champs de résultats. Un nombre sans source est refusé — la façon la plus courante dont les résumés se trompent.

L'indépendance est comptée

Trois résultats issus d'une seule exécution forment une ligne d'évidence, pas trois. Les lignes qui partagent des données ou une source fusionnent.

Les exclusions exigent de la puissance

« Exclut » seulement après avoir montré qu'une recherche retrouve une réponse plantée. Sinon, le résultat n'est pas concluant.

Les auteurs ne se relisent pas eux-mêmes

Seuls comptent les verdicts des relecteurs désignés, et jamais sur leur propre travail. Ceux des autres sont gardés comme commentaires.

Les instruments parlent pour eux-mêmes

Seul l'exécuteur du laboratoire enregistre une exécution de laboratoire. Une exécution que vous décrivez est marquée comme votre rapport.

L'arithmétique du jamais

défaillances en tests laissent encore sur un million d'utilisations.

Un agent qui n'en voit aucune dans ses tests écrit « cela n'arrive jamais ». Le registre refuse cette phrase et demande les décomptes, puis indique ce qu'ils laissent ouvert à l'échelle où vous déployez.

L'arithmétique, pas à pas

défaillances non exclues sur utilisations, à 95 % de confiance, à partir de sur tests.

Cette page a un registre

Nous soumettons cette page aux règles qu'elle décrit.

Les chiffres ci-dessus sont des affirmations dans un registre HypGraph construit avec la page. L'instrument de la compilation les mesure, un relecteur mesure chacune à nouveau autrement, et le texte de la page est vérifié contre le registre avec hypgraph check : un chiffre que le registre ne contient pas n'arrive pas sur la page. Ouvrez-le dans l'application ci-dessus avec Le registre de cette page, ou téléchargez le bundle et vérifiez-le vous-même.

Confiance

Ce que montre le registre, et ce qu'il n'affirme pas.

✓ Il montre

  • qu'aucun événement n'a été modifié après son écriture : chaque écriture est hachée dans une chaîne que chacun peut revérifier ;
  • quels nombres d'une affirmation sont liés à quel résultat, et quelle exécution l'a produit ;
  • qui a vérifié quoi, sur quelle version, et si cette version est toujours en vigueur ;
  • ce qui tombe si une prémisse est retirée.

— Il n'affirme pas

  • qu'une affirmation est vraie. Il vérifie ce qui est écrit par rapport à ce qui est enregistré ;
  • qu'il fait mieux raisonner un modèle. Il garde hors du registre les surinterprétations d'un modèle ;
  • quoi que ce soit sur la télémétrie qui voyage dans un bundle : elle est hors de la chaîne de hachage ;
  • vérifier les événements qu'un bundle restreint masque. La vérification signale quand un bundle est restreint.

Il tourne là où vous le lancez : un fichier local, sans compte et sans appels réseau propres. Les versions sont publiées sur PyPI depuis GitHub Actions par publication de confiance.
