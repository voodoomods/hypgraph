Bac à sable

Essayez de lui faire passer une affirmation.

Voici le vrai moteur — le même paquet Python que vous installeriez avec pip install — qui tourne dans votre navigateur, sur l'enquête de Broad Street de 1854. Écrivez une affirmation sur les résultats de Snow et regardez ce que le registre en fait. Les affirmations s'écrivent en anglais : le moteur lit l'anglais.

Python via Pyodide, environ 10 Mo la première fois, en cache ensuite. Rien n'est envoyé nulle part.

Défi : faire passer une affirmation fausse

Chaque défi, c'est un résultat et une affirmation qu'il ne soutient pas. Écrivez seulement l'énoncé : toutes les valeurs sont liées pour vous, comme un agent honnête les lierait. Si le registre accepte une phrase qui dit ce que demande l'objectif, vous avez trouvé un contournement. Merci de le signaler, pour que la prochaine version le refuse.
